# Mysterious-Number

**Mysterious-Number** is an interactive web-based game where players try to guess a hidden number between **1 and 100** within a limited number of attempts. The game provides feedback after each guess to indicate how close the player’s guess is to the hidden number.

## Features
- **Limited Attempts:** Players have **10 guesses** to find the correct number.  
- **Clues for Guidance:** The game gives hints to show whether the guess is too high, too low, or close.  
- **Restart Option:** Players can restart the game at any time.  
- **User Instructions:** Clear instructions are provided before starting the game to ensure smooth gameplay.  

## Technologies Used
- **HTML** – Structure of the game interface  
- **CSS** – Styling and visual enhancements  
- **JavaScript** – Game logic and interactivity  

## How to Play
1. Open the game in your browser.  
2. Read the instructions carefully.  
3. Enter your guesses one by one.  
4. Observe the clues provided after each guess.  
5. Try to guess the hidden number within **10 attempts** to win!  
6. Restart the game anytime if needed.
